预编译好的是32位程序，如果在64位系统中运行，需要安装以下软件：
sudo apt-get install lib32ncurses5

NS2模拟器依赖环境
sudo apt-get -y install libx11-dev libxmu-dev libxmu-headers libxt-dev libtool g++ patch tcl tk tcl-dev tk-dev gnuplot

必须安装的软件(依赖动态库，编译好拷贝使用会有问题)：
1.xvidcore安装
#来源：http://downloads.xvid.org/downloads/xvidcore-1.3.2.tar.gz
tar -zxvf xvidcore-1.3.2.tar.gz
cd xvidcore/build/generic
./configure --prefix=/usr
make
sudo make install

2.ffmpeg安装
#来源：https://ffmpeg.org/releases/ffmpeg-4.2.3.tar.gz
tar -zxvf ffmpeg-4.2.3.tar.gz
cd ffmpeg-4.2.3
./configure --enable-shared --disable-x86asm
make
sudo make install

3.GPAC安装
sudo apt-get install build-essential pkg-config g++ git scons cmake yasm zlib1g-dev
git clone https://github.com/gpac/gpac.git
./configure --static-bin --prefix=/usr/local/MP4Box
make
sudo make install
