## 使用说明

- 作业源码、实验报告、试卷、课件和复习材料按课程浏览。资料中保留了原作者署名。
- 安装包、依赖目录、IDE 缓存、编译产物、可下载数据集和训练权重不入库；运行项目时需自行安装依赖、准备数据和权重。
- 部分实验压缩包已筛选解压；与现有目录不同的压缩包版本单独存放，避免覆盖。
- Jupyter 笔记本保留代码和文字，清理运行输出。个别连接配置使用占位值，运行前请自行填写。
- 同一课程内内容完全相同的文档只保留一份，见[重复文档索引](./docs/重复文档索引.csv)。
- 其余筛选规则和未上传的大文件见[整理说明](./整理说明.md)。

资料用于个人学习参考，课程要求和知识点以当期教学内容为准。原作者作品的权利归原作者所有；本仓库未为第三方资料另行授予许可。
