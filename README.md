## 使用指南

- **复习备考**：从课程导航进入，查找对应的课件、习题、试卷与复习笔记。
- **实验与课程设计**：结合实验要求和报告阅读源码，理解实现思路与实验过程。
- **运行项目**：参考项目中的说明配置环境，并自行准备依赖、数据和个人密钥。

资料供学习参考，具体课程内容与考核要求以当期教学安排为准。
